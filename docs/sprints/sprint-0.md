\# Sprint 0 — Fundação técnica



\## Objetivo

Preparar uma base organizada, segura e reproduzível para o e-commerce.



\## Entregas

\- Projeto Django inicializado.

\- Ambiente virtual Python configurado.

\- PostgreSQL criado.

\- Estrutura de documentação e dependências criada.

\- Git configurado para ignorar segredos e arquivos gerados.



\## Critérios de aceite

\- O Django inicia localmente.

\- Dependências podem ser reinstaladas por `requirements/base.txt`.

\- Senhas não são versionadas.

\- Estrutura de pastas segue a arquitetura definida.
