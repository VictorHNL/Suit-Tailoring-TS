# Backend Java

Backend do Suit Tailoring em Java 25 LTS e Spring Boot 4.1.1.

## Executar localmente

Após instalar a JDK 25, use o Maven Wrapper:

```powershell
.\mvnw.cmd spring-boot:run
```

As configurações de banco serão adicionadas por variáveis de ambiente e as mudanças de schema por migrações Flyway.
